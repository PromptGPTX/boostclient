## 🎮 Key Features

### 🌟 FastClient-Inspired Sleek UI
- **PLAY Tab**: 3D player skin avatar preview, bold LAUNCH GAME button, version selector dropdown (1.18.2 to 26.3+), "+ Add a Profile" shortcuts, bottom news banners ("Cosmetics", "Giveaways"), and interactive right sidebar with quick Discord join (`discord.gg/TUTvzCmtyD`), Webstore, and Friends feed.
- **PROFILES Tab**: Profile grid view with search bar, version filters, creation wizard, and 1-click Play/Mods/Resource Packs management.
- **SERVERS Tab**: Full local server management with live player counts, real-time metrics, interactive console, and zero-port tunneling.
- **ACCOUNT Tab & Wardrobe**: Multi-account manager (Offline/Cracked & Microsoft OAuth) + 3-slot skin library and custom cape manager with **animated GIF cape support**.
- **SETTINGS Tab**: Theme customization, JVM RAM allocation slider, and update preferences.

### 🎽 Wardrobe & Animated GIF Capes
- **3-Slot Skin Library**: Keep up to three 64×64 PNG skins (under 25 KB) and switch active slots instantly.
- **Animated GIF Capes**: Upload any custom GIF or choose from default capes (Creeper, Angel, Dragon, Rainbow, Fire, Heart, Star).
- **Cross-Player Visibility**: All players using BoostClient and the BoostX mod can see each other's custom skins and animated GIF capes in multiplayer.
- **In-Game Skin Changer**: Quick wardrobe access directly from the in-game pause menu.

### ⚡ BoostX All-in-One Client Mod (100+ Modules)
BoostClient includes the pre-packaged BoostX suite providing:
- **Default Hotkeys**:
  - `Right-Shift` ➔ BoostX Client GUI (100+ module toggles)
  - `B` ➔ Instant Fullbright
  - `C` ➔ Smooth Optical Zoom
  - `F` ➔ Freelook 360° Perspective Camera
  - `F9` ➔ Chunk Borders & Light Overlay
- **Performance Modules**: Sodium integration, Lithium physics optimizations, FerriteCore memory cleaner, ImmediatelyFast, Entity Culling, More Culling, Dynamic FPS, and Aikar's G1GC optimization flags.
- **PvP & HUD**: Keystrokes, CPS Counter, Combo Counter, Reach Display, Armor Durability Warning, Coordinates (XYZ), Ping HUD, FPS HUD, and Custom Crosshairs.

### 🌐 Aternos-Style Zero-Port Server Manager
- Host Minecraft servers on your PC without router port-forwarding.
- Automated **Playit.gg** and **Cloudflare Tunnels** generate public addresses (e.g. `*.gl.joinmc.link`) for friends to join.
- One-click server software switcher (Paper, Purpur, Fabric, Forge, NeoForge, Velocity, Vanilla).
- One-click "Open Server Folder in File Explorer" (`shell.openPath`).

### 🔄 GitHub-Powered Safe Update Engine
- Connected to `https://github.com/PromptGPTX/boostclient`.
- Checks for client and BoostX mod releases automatically.
- Installs critical updates and user-approved feature updates without losing profiles, worlds, or user configurations.
- On-demand asset and mod downloads (`mods/versions.json`) ensure a lightweight initial launcher installer.

## 📥 Download & Installation

1. Download the latest installer from [Releases](https://github.com/PromptGPTX/boostclient/releases):
   - **`boostclient-setup-1.2.0.exe`** (Single-file NSIS installer for Windows x64)
2. Run the setup installer and launch **BoostClient**.
3. Log in with your Microsoft account or choose an offline username.
4. Select your preferred version and click **LAUNCH GAME**.
