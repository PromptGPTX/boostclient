# ❓ Frequently Asked Questions (FAQ)

### Is BoostClient completely free to use?
Yes! BoostClient is 100% free with no subscriptions, locked cosmetic paywalls, or hidden fees. All cosmetic features (including animated GIF capes and custom skins) are unlocked for everyone.

### Where is BoostClient data saved?
All accounts, profiles, downloaded assets, and servers are stored inside your Windows user directory at `%APPDATA%\.boostclient` (matching standard launcher paths like `.minecraft`, `.tlauncher`).

### Does BoostClient support cracked/offline accounts?
Yes. You can add offline accounts with any username, as well as official Microsoft accounts with full Xbox Live OAuth 2.0 PKCE authentication.

### How do I see other players' custom skins and capes?
Whenever you and other players use BoostClient with the BoostX mod or connect to a server with the BoostX Server Engine, all custom skins and animated GIF capes are synchronized over the network.

### Why is the installer only ~79 MB?
To prevent massive downloads and keep updates instant, BoostClient downloads heavy runtime dependencies (like game versions, mods, and server jars) on-demand from official repositories and GitHub.

### Can I install standard CurseForge and Modrinth mods?
Yes! BoostClient features a full Modrinth and CurseForge content browser with 1-click installation for Fabric, Forge, and NeoForge mods, resource packs, and shader packs.
