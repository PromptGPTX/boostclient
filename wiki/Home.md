## 🌟 Core Features

1. **1,980+ FPS Performance Stack**:
   - Engineered with Aikar's tuned JVM GC parameters, asynchronous chunk packet compression, and tick stabilization.
2. **Onboarding Progression**:
   - Clean, step-by-step account configuration -> profile creation -> 1-click launch.
3. **Multiplayer Cosmetic Relays**:
   - Upload custom PNG skins and animated GIF capes. Every player using BoostClient and the BoostX mod sees each other's custom cosmetics in multiplayer.
4. **Zero-Config Local Server Manager**:
   - Self-host Paper, Purpur, Fabric, or Forge servers locally on your PC. Automated Playit.gg tunneling delivers a public domain (`*.gl.joinmc.link`) with zero router port forwarding.
5. **On-Demand Distribution**:
   - Client downloads are kept compact (79 MB setup). Heavy mod jars and server runtime components are fetched automatically on-demand from GitHub.
