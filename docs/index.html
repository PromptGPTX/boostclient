Getting Started

BoostClient provides both offline (cracked) and Microsoft Xbox Live OAuth authentication. Create a profile, pick your Minecraft version (1.18.2 to 26.3+), and hit LAUNCH GAME.

BoostX In-Game Controls

When launching any profile with BoostX installed, use the following default hotkeys: 

Right-Shift  -> Open BoostX Client Menu (100+ Modules)
B            -> Fullbright Toggle
C            -> Zoom
F            -> Freelook (Perspective Camera)
F9           -> Chunk Borders & Light Overlay

Aternos-Style Server Hosting

BoostClient automatically downloads Paper, Purpur, or Fabric server JARs on-demand and manages tunneling so friends can join using a public Playit link or custom Cloudflare domain.
