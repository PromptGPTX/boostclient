Frequently Asked Questions

Have questions about BoostClient? We've got answers.

❓ Is BoostClient free to use?
Yes! BoostClient is 100% free and open-source. There are no subscriptions, paywalls, or paid cosmetics. All cape designs and 3D wardrobe features are free for everyone.
🔒 Is BoostClient safe to use?
Absolutely. BoostClient contains no spyware, ads, or hidden miners. The entire source code is openly hosted on GitHub at PromptGPTX/boostclient for community auditing.
🧩 Does BoostClient work with Minecraft mods?
Yes. BoostClient has first-class support for Fabric, Forge, NeoForge, and Quilt loaders across all versions from 1.18.2 to 1.21.6+. It also features an integrated Modrinth store for 1-click installations.
💻 What platforms does BoostClient support?
BoostClient supports Windows 10/11 (64-bit), macOS (Intel & Apple Silicon), and Linux (AppImage & deb). The single installer is optimized for Windows.
🎽 How do animated GIF capes work in multiplayer?
Upload any 64×32 or animated GIF cape in the Wardrobe tab. When you join servers, BoostClient and our embedded BoostX client mod broadcast cape frames to other BoostClient and BoostX mod users, rendering full animated capes in real-time.
🌍 Do I need port-forwarding to host servers?
No! BoostClient includes automated Playit.gg and Cloudflare tunneling. When you start your server, it generates a joinable public link (like yourname.gl.joinmc.link) that your friends can use immediately.
